# 0006. Одна форма фабрики в DI эффектов

- Статус: реализовано
- Дата: 2026-11-23
- PR: #10
- Связано: 0002 (DI для обработчиков эффектов), 0005 (гарды); README → «DI»

## Контекст

При переходе к гардам (0005) сформулирован принцип минималистичного ядра: в ядре только общая форма, частные случаи сводятся к ней вне ядра. В DI эффектов было три вида фабрик — готовый объект, асинхронная функция и асинхронный генератор, хотя первые два — частные случаи генератора. А общее ядро DI держало время жизни зависимостей, которое нужно только DI эффектов: гардам приходилось изображать фиктивное время жизни из одного значения.

## Цель и границы

- Оставить в DI эффектов одну форму фабрики, а из общего ядра DI убрать время жизни.
- Не входят: хелперы, которые сводят частные случаи к общей форме.

## Решение

- **Фабрика — только асинхронная генераторная функция.** Код до `yield` создаёт зависимость, `yield` отдаёт её, код после `yield` закрывает. Зависимость без кода закрытия — генератор, который отдаёт значение и завершается.
- **Готовый объект и асинхронную функцию** позже сведут к генератору хелперы вне ядра.
- **Ограничение «готовый объект — только на время жизни приложения» снято:** время жизни задаётся в объявлении зависимости, а хелпер о нём не знает. Это безвредно, объект просто отдаётся как есть.
- **Общее ядро DI без времени жизни:** в нём остались сопоставление по типу и имени, поиск циклов и сортировка. Время жизни целиком ушло в DI эффектов, а значения гардов хранятся в простом словаре.

## Развилки

### Одна форма фабрики или несколько

- Выбрано: одна, самая общая.
- Почему: ядро минималистично, частные случаи — вне ядра.
- Цена: генератор без кода закрытия создаётся примерно за 0,9 мкс против 0,06 мкс у асинхронной функции, то есть примерно в 15 раз дороже. Заметно это только для зависимостей со временем жизни эффекта, и то на фоне ввода-вывода обработчиков эффектов разница незаметна. Если станет мешать, ядро сможет вызывать функцию из хелпера напрямую, не меняя API.

## Сочетание с другими фичами

- Гарды: тот же принцип, в ядре один вид гарда — генераторная функция.

## Открытое

- Хелперы для готового объекта и асинхронной функции. Грабли, найденные на хелпере для гардов (0005), относятся и к ним.
