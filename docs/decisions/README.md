# Записи о решениях

Почему фичи устроены так, а не иначе: контекст, развилки с отвергнутыми вариантами, нюансы и сочетание с другими фичами. Что есть сейчас — в [README](../../README.md), здесь — как к этому пришли.

## Правила

- Одна запись — одна фича, файл `NNNN-slug.md` по [шаблону](template.md), номера сквозные.
- Запись пишется в ветке фичи и коммитится в том же PR. После мержа не переписывается, меняются только статус и строка «Пересмотрено».
- Пересмотр решения — новая запись: в старой статус «заменено NNNN» или строка «Пересмотрено: NNNN (что именно)».
- Новая запись добавляется в индекс ниже.
